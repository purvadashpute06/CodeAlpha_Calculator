CodeAlpha Calculator

A simple and responsive Calculator Web Application developed using HTML, CSS, and JavaScript as part of the CodeAlpha Frontend Development Internship.

Features

- Basic Arithmetic Operations
- Addition (+)
- Subtraction (-)
- Multiplication (×)
- Division (÷)
- Percentage Calculation
- Clear (AC) and Delete (DEL) Buttons
- Real-time Result Display
- Keyboard Support
- Responsive User Interface

Technologies Used

- HTML5
- CSS3
- JavaScript
